RPi5 M.2 Dual HAT Setup
=======================

Step 1 - Flash Storage Media

  Use Raspberry Pi Imager to flash both the SSD and SD card with:

    Device:           Raspberry Pi 5
    Operating System: Raspberry Pi OS (64-bit)


Step 2 - Configure the M.2 Dual HAT

  Follow the setup instructions from Seeed Studio for connecting and
  configuring the M.2 Dual HAT with your Raspberry Pi:

    https://wiki.seeedstudio.com/raspberry_pi_5_uses_pcie_hat_dual_hat/

#### HAILO CHIP Setup
####################
##############
# After Reboot 

#1) Write and read speed command

# FOR SINGLE M2 HAT
sudo dd if=/dev/zero of=/mnt/nvme/testfile bs=1M count=1024 oflag=direct
sudo dd if=/mnt/nvme/testfile of=/dev/null bs=1M iflag=direc

# FOR DUAL M2 HAT
sudo dd if=/dev/zero of=tempfile bs=1M count=1024 oflag=direct
sudo dd if=/dev/zero of=tempfile bs=1M count=1024 

# M.2 dual Hat	Read & Read	Write & Write	Read & Write
# PCIe 3.0	822MB/s	716MB/s
# PCIe 2.0	431 MB/s	389MB/s


#2) Update Config.txt
 sudo nano /boot/firmware/config.txt
ADD THE FOLLOWING IN UNDER [all]  if not there
dtparam=pciex1
dtparam=pciex1_gen=3
dtoverlay=pciex1-compat-pi5,no-mip,mmio-hi

Step 3 (Optional) - Create ISO Image

  On your host system, attach the SD card and create an ISO image.

  1. Install GNOME Disks:

       sudo apt install gnome-disk-utility

  2. Open Disks, select the SD card, click the three-dot menu, choose
     a filename, and create the ISO image.
